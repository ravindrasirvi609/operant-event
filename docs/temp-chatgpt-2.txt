  INDEX(organization_id, email)

  INDEX(organization_id, created_at)

# 23. Tenant isolation

Ye rule hum backend mein mandatory rakhenge:

```text
Request
   ↓
Authenticated User
   ↓
Organization Context
   ↓
Conference Access Check
   ↓
Database Query
```

Example:

```text
GET /conferences/:conferenceId/abstracts
```

Backend blindly:

```sql
SELECT * FROM abstracts
WHERE conference_id = ?
```

nahi karega.

Pehle check:

```text
conference belongs to current organization?
        ↓
       YES
        ↓
query abstracts
```
